## Introduction

@zeus filament-locationpickr-field provides a simplified location picker for Filament forms and infolists using Google Maps.

**[Github](https://github.com/lara-zeus/filament-locationpickr-field) · [Packagist](https://packagist.org/packages/lara-zeus/filament-locationpickr-field) · [Discord](https://discord.com/channels/883083792112300104)**

## Features

- Location picker form field for Filament
- Location picker infolist entry for Filament
- Configurable defaults for map behavior (zoom, location, controls)
